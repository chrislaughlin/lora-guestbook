## Design Context

### Users
This public guestbook is for people watching live LoRa radio messages arrive on an event or installation display. Viewers may be standing back from the screen, glancing between conversation and the display, and looking for a sense that the radio network is alive.

### Brand Personality
Retro-futuristic, atmospheric, legible. The interface should feel like a deep-space signal monitor rather than a conventional web feed.

### Aesthetic Direction
Use a dark display-first theme inspired by the provided screenshot: cosmic depth, faint technical grid structure, framed regions, and luminous message cards. Ignore message avatars. The primary memorable behavior is slow DVD-screensaver-style drifting, where each message moves independently around the field and appears to bounce within the display.

### Design Principles
- Prioritize distance legibility over dense reading: high contrast, compact copy, and clear sender names.
- Make the display feel live without making it frantic: slow transform-based motion, no layout animation.
- Keep the radio/sci-fi texture purposeful and restrained so messages remain the focus.
- Preserve the existing guestbook contract, live update behavior, retry behavior, and safe text rendering.
- Respect reduced-motion preferences with a stable, readable layout.
